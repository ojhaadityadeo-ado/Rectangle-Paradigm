British Flag Theorem

In a rectangle \(ABCD\), for any point \(P\), the sum of the squared distances to one pair of opposite vertices equals the sum for the other pair.

\[\boxed{PA^2+PC^2=PB^2+PD^2}\]

The visual heart of the proof

The dashed guides split the rectangle into four horizontal/vertical component lengths. By Pythagoras, the square on each coloured segment is built from two of the four component-square areas below.

The same four square-areas

\(x^2\)
\((a-x)^2\)
\(y^2\)
\((b-y)^2\)
Build the pair \(A,C\)
\[PA^2=x^2+y^2\] \[PC^2=(a-x)^2+(b-y)^2\]
\[PA^2+PC^2=x^2+(a-x)^2+y^2+(b-y)^2\]
Build the pair \(B,D\)
\[PB^2=(a-x)^2+y^2\] \[PD^2=x^2+(b-y)^2\]
\[PB^2+PD^2=x^2+(a-x)^2+y^2+(b-y)^2\]
Both sums are made from exactly the same four square-areas.
\[\boxed{PA^2+PC^2=PB^2+PD^2}\]

The same algebraic identity also extends to points outside the rectangle; the interior position is used here only to make the component lengths visually immediate.

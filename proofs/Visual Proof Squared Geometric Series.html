$$ 1 + 2x + 3x^2 + 4x^3 + \dots = \sum_{k=0}^{\infty} (k+1)x^k = \frac{1}{(1-x)^2} $$

Proof Progression

1. The Bounding Square Consider a large square whose width and height are exactly equal to the infinite geometric sum $\sum_{i=0}^{\infty} x^i = \frac{1}{1-x}$. Total Area is $\frac{1}{(1-x)^2}$.
2. The Cartesian Grid We subdivide the square into an infinite grid. Cell $(i,j)$ has width $x^j$ and height $x^i$. Thus, every cell is a true rectangle with area $x^{i+j}$.
3. Summing by Rows Let's sum horizontally. Row $i$ equals $x^i(1 + x + x^2 + \dots) = \frac{x^i}{1-x}$. Adding up all the rows confirms the total area evaluates to $\frac{1}{(1-x)^2}$.
4. Summing by Anti-Diagonals Now group cells diagonally where $i+j = k$. For example, $k=2$ contains exactly 3 cells $(x^2, x^2, x^2)$. Every diagonal $k$ has exactly $k+1$ cells of area $x^k$.
5. The Final Equation Summing all the diagonals gives $1 + 2x + 3x^2 + \dots$, which must equal the exact same total grid area computed in step 3!

Deriving the Algebraic Identity

1. Area via Rows

The visual grid physically embodies a multiplication table. If we compute the total area by summing each row independently, row $i$ has a constant height of $x^i$, and its width stretches across the entire box:

$$ \text{Row } i = x^i(1 + x + x^2 + \dots) = \frac{x^i}{1-x} $$

Summing all rows $\sum_{i=0}^\infty \frac{x^i}{1-x}$ yields the total area $\frac{1}{(1-x)^2}$. This mathematically confirms the "squaring" of the standard geometric series.

2. Area via Anti-Diagonals

Instead of reading horizontally, what if we sum the cells diagonally from bottom-left to top-right? Let's track cells where the row index $i$ and column index $j$ add up to a constant $k$.

$$ \text{For } i+j=k, \text{ Area} = x^i x^j = x^k $$

There are exactly $k+1$ possible pairs of non-negative integers $(i,j)$ that sum to $k$. Thus, diagonal $k$ contributes precisely $(k+1)x^k$ to the total area. Setting the total diagonal sum equal to the total area derives our identity!

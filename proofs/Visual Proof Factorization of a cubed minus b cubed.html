Visual Proof: Factorization of $a^3 - b^3$

$$\text{Remaining Area} = a^3 - b^3$$
Base $(a)$ 5.0
Cutout $(b)$ 2.0
Step: 0 / 4

Start with a rectangle of area $a^3$ (dimensions $a^2 \times a$) and subtract a corner of area $b^3$ (dimensions $b^2 \times b$).

How this 2D Proof Works

We can elegantly prove 3D volume identities using 2D geometry by representing cubed values as rectangles: $a^3 = a^2 \times a$.

  1. The Setup: We start with a large $a^2 \times a$ block and remove a $b^2 \times b$ cutout from the corner. The remaining area is exactly $a^3 - b^3$.
  2. Partitioning: This remaining L-shape naturally splits into a Top rectangle ($a^2 \times (a-b)$) and a Bottom rectangle ($(a^2-b^2) \times b$).
  3. Constant Area Reshaping: The bottom rectangle has an area of $b(a^2-b^2)$. Since $a^2-b^2$ factors to $(a-b)(a+b)$, the area can be written as $b(a-b)(a+b)$. We visually reshape this block into a new rectangle with height $(a-b)$ and width $ab + b^2$.
  4. The Final Combination: Because the reshaped bottom block now shares the exact same height $(a-b)$ as the top block, they slide together perfectly to form one unified rectangle!
$$\text{Total Width} = a^2 + ab + b^2$$ $$a^3 - b^3 = (a-b)(a^2 + ab + b^2)$$

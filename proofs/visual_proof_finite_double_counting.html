Finite Double Counting

$$ \sum_{i=1}^{m} \left( \sum_{j=1}^{n} a_{ij} \right) = \sum_{j=1}^{n} \left( \sum_{i=1}^{m} a_{ij} \right) $$

Proof Progression

1. The 2D Array Consider an $m \times n$ matrix of values $a_{ij}$. We want to find the grand total of all the elements in this grid.
2. Grouping by Rows First, we calculate the inner sum across each row horizontally. This gives us a row total $R_i = \sum_{j=1}^n a_{ij}$ for every row $i$.
3. Totaling the Rows By adding all the row totals vertically, we obtain the grand total: $\text{Total} = \sum_{i=1}^m R_i$. This is the Left-Hand Side of our equation.
4. Grouping by Columns Alternatively, calculate the inner sum down each column vertically. This gives us a column total $C_j = \sum_{i=1}^m a_{ij}$ for every column $j$.
5. Totaling the Columns By adding all the column totals horizontally, we obtain the grand total: $\text{Total} = \sum_{j=1}^n C_j$. This is the Right-Hand Side.
6. The Equivalence Because both methods sum exactly the same set of finite elements, the results are identical. The order of summation can be safely swapped!

Mathematical Context

1. Area of a Rectangle

If we set every cell value to $a_{ij} = 1$, the double sum simply counts the total number of $1 \times 1$ unit squares in the grid.

$$ \sum_{i=1}^{m} \sum_{j=1}^{n} 1 = m \times n $$

Counting by rows yields $m \times n$, while counting by columns yields $n \times m$. This double-counting principle is the fundamental proof that the area of a rectangle is commutative.

2. General Applications

The ability to interchange summation signs is a powerful tool used across many fields of mathematics:

  • Combinatorics: Counting sets in two different ways to prove identities (like combinations and permutations).
  • Probability: Marginalizing joint probability tables $P(X,Y)$ to find $P(X)$ or $P(Y)$.
  • Matrix Algebra: Proving properties like $\text{Tr}(AB) = \text{Tr}(BA)$.

3. Fubini's Theorem

Finite double counting is the discrete analog of Fubini's Theorem in multivariable calculus. Just as we can swap the order of finite sums:

$$ \int_a^b \left( \int_c^d f(x,y) \,dy \right) dx = \int_c^d \left( \int_a^b f(x,y) \,dx \right) dy $$

Integrating over $y$ first is akin to summing a column. Integrating over $x$ first is akin to summing a row.

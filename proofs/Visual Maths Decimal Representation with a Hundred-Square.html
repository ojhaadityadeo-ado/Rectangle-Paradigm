Decimal Representation with a Hundred-Square

A \(10\times10\) square has 100 small squares. So if we shade some of them, we can see hundredths. This makes it easy to understand decimals like \(0.37\).

How many hundredths are shaded? 37
37 shaded squares out of 100
What the picture means

Every tiny square is one hundredth

The whole big square is 1 whole. Since it is split into 100 equal tiny squares, each tiny square is worth \(\frac{1}{100}\).

Decimal sentence
\(0.37=\frac{37}{100}\)
What is happening?
We shaded 37 tiny squares. That means 37 hundredths. So the fraction is \(\frac{37}{100}\), and the decimal name is \(0.37\).
Quick facts
Shaded squares 37
Fraction 37/100
Decimal 0.37
Not shaded 63
\(37\) hundredths \(=\frac{37}{100}=0.37\)

How to explain this to small kids

Start with one whole square. Tell the child that the big square means one whole thing.
Cut the whole into 100 equal pieces. Because the square is \(10\) across and \(10\) down, it has \(10\times10=100\) tiny squares.
Each tiny square is one hundredth. So one tiny square means \(\frac{1}{100}\), two means \(\frac{2}{100}\), and so on.
Count the shaded tiny squares. If 37 tiny squares are shaded, that is \(\frac{37}{100}\).
Write the decimal. \(\frac{37}{100}\) is written as \(0.37\), which we read as “thirty-seven hundredths”.

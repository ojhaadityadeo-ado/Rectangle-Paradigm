Integration Process

1. The Interval Consider a continuous function $f(x)$ strictly defined over the bounded interval $[a, b]$.
2. The Definite Integral The exact value of the integral $\int_a^b f(x)\,dx$ is represented by the true shaded area under the curve.
3. The Infimum ($m$) Find the absolute lowest value the function reaches within the interval, denoted as $m = \inf f(x)$.
4. The Lower Bound Construct a rectangle of width $(b-a)$ and height $m$. Because $m \le f(x)$ everywhere on the interval, this rectangle fits entirely under the curve. Area = $m(b-a)$.
5. The Supremum ($M$) Find the absolute highest value the function reaches within the interval, denoted as $M = \sup f(x)$.
6. The Upper Bound Construct a rectangle of width $(b-a)$ and height $M$. Because $M \ge f(x)$ everywhere, this rectangle completely encapsulates the curve area. Area = $M(b-a)$.
7. Conclusion Visually overlaying all three reveals a strict ordering of areas. The integral is bounded by the inscribed and circumscribed rectangles!

Mathematical Formulation

1. Properties of the Function

By the Extreme Value Theorem, if $f(x)$ is continuous on a closed interval $[a,b]$, it must attain an absolute minimum $m$ and an absolute maximum $M$. Therefore, for all $x \in [a,b]$:

$$ m \le f(x) \le M $$

This guarantees that the curve is structurally restricted between two horizontal lines $y=m$ and $y=M$.

2. Integration Preserves Inequality

A fundamental property of the Riemann Integral states that if $g(x) \le f(x) \le h(x)$ on an interval, then the integrals of the functions follow the same inequality. Taking the integral of our bounds:

$$ \int_{a}^{b} m\,dx \le \int_{a}^{b} f(x)\,dx \le \int_{a}^{b} M\,dx $$

Since $m$ and $M$ are constants, integrating them simply yields the area of rectangles, completing our proof: $m(b-a) \le \int f(x) \le M(b-a)$.
